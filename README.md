# CGV 예매 오픈 알리미 + 좌석 자동 확보

지정한 (상영관·날짜·영화)의 CGV 예매가 열리거나 취소표가 나오면 알려주고,
원할 경우 로그인된 크롬을 직접 조종해 좌석 선택까지 자동으로 마쳐 줍니다.
**결제는 항상 사람이 합니다.** 노트북에서 직접 실행하는 프로그램입니다
(Raspberry Pi / Docker 운영은 하지 않습니다 — 실제 크롬 브라우저를 띄워야 해서
컨테이너에 맞지 않습니다).

## 무엇을 하는가

- **감시·알림**: CGV 공개 조회 API를 주기적으로 확인해, 등록한 (상영관·영화·날짜) 조합의
  예매가 열리면 Discord로 알립니다. 관 필터(예: IMAX)를 걸면 원하는 관의 회차가 열릴 때만
  알립니다.
- **좌석 자동 확보** (선택 기능, 감시 항목별로 켬/끔): 조건을 만족하면 로그인된 크롬을 조종해
  회차를 고르고, 좌석 지도를 폴링하며 빈자리가 나오는 즉시 클릭해 잡습니다.
  **결제 페이지에 닿는 순간 모든 자동 동작을 멈추고** 사람을 부릅니다.
- 로그인과 결제는 프로그램이 절대 대신하지 않습니다. 계정 정보(아이디/비밀번호)는
  코드·설정·로그 어디에도 저장하지 않습니다.

## 준비

의존성은 [uv](https://docs.astral.sh/uv/)로 관리합니다. `uv run`이 가상환경을 자동으로
만들고 `uv.lock`에 잠긴 버전 그대로 설치하므로 가상환경을 직접 켤 필요가 없습니다.
**`pip install`이나 맨 `python`은 쓰지 않습니다** — 항상 `uv run`을 앞에 붙입니다.

```
uv sync --extra dev
uv run playwright install chromium
```

`.env.example`을 `.env`로 복사하고 `DISCORD_WEBHOOK_URL`을 채웁니다.

```
cp .env.example .env
```

## 실행

```
uv run python run.py
```

기본적으로 `http://0.0.0.0:8080`에서 서버가 뜹니다. 브라우저로
`http://localhost:8080`에 접속하면 웹 UI가 열립니다.

### 첫 사용 (브라우저 로그인)

좌석 자동 확보 기능을 쓰려면 CGV 로그인이 한 번 필요합니다.

1. 웹 UI에서 **"브라우저 열기"** 버튼을 누릅니다. Playwright 전용 프로필로 크롬 창이 뜹니다.
2. 뜬 크롬 창에서 CGV에 **직접** 로그인합니다. (프로그램은 아이디/비밀번호를 보지도,
   저장하지도 않습니다.)
3. 로그인 세션은 전용 프로필(`~/.cgv-watcher/chrome-profile`)에 남아 다음 실행에도
   유지됩니다. 세션이 끊기면 헌팅이 시작되지 않고 "로그인 필요" 알림이 옵니다.
4. 웹 UI에서 감시할 (극장·영화·날짜)를 등록하고, 좌석 자동 확보를 원하면 인원·
   중앙 기준 오프셋·선호 시각·관 필터를 설정합니다.

### 테스트

```
uv run pytest tests/
```

## 환경 변수

| 변수 | 설명 | 기본값 |
| --- | --- | --- |
| `DISCORD_WEBHOOK_URL` | 예매 오픈·좌석 확보·오류 알림을 보낼 Discord 웹훅 URL. 미설정 시 알림 전송을 시도하면 오류가 발생합니다. | (없음, 필수) |
| `CGVWATCH_DATA` | 설정·감시목록을 저장할 디렉터리 (`config.json` 위치). | 사용자 홈 디렉터리 |
| `PORT` | 웹 서버가 바인딩할 포트. | `8080` |

## 안전 정책

- **자동 로그인을 만들지 않습니다.** 계정 정보는 프로그램이 다루지 않습니다. 로그인은
  사람이 뜬 크롬 창에서 직접 합니다.
- **결제를 자동화하지 않습니다.** 결제 페이지에 도달하는 즉시 모든 자동 동작을 멈춥니다.
- **좌석 폴링 간격 하한은 1초**입니다. 429(과도한 요청)를 받으면 대기 시간을 늘립니다.
- **동시 헌팅은 1개**입니다. 이미 진행 중인 헌팅이 있으면 나머지는 대기합니다.
- 좌석을 한 번 확보하면 추가 시도를 하지 않습니다 (중복 선점 방지).

## API

- `GET /healthz` — 헬스체크
- `GET/POST/DELETE /api/watches` — 감시 목록 조회/추가/삭제
- `GET/PUT /api/settings` — 설정 조회/변경
- `GET /api/movies`, `GET /api/theaters` — CGV 상영관/영화 목록 조회
- `GET /` — 웹 UI
